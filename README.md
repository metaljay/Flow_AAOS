# Flow for AAOS

### 🚗 An AAOS-focused Flow fork, tuned for the Polestar 3

Larger, easier-to-use controls and a layout adapted for the Polestar 3's in-car display.

[**Download the latest release**](https://github.com/metaljay/Flow_AAOS/releases)

</div>

---

## ✨ What this fork changes

- 🧭 **Bottom navigation at every window size** — Home, Shorts, Music, Subscriptions, and Library stay within easy reach.
- 👀 **Made for a large in-car display** — enlarged Material 3 typography, icons, touch targets, and player controls, with 72 dp minimum top and bottom app bars.
- 🎬 **2160p default video quality** — used when no quality preference has been saved; your saved setting and the video's available quality are respected.
- 🚘 **AAOS integration** — automotive app metadata, a car-launcher entry, and media browsing support.
- 📷 **Camera remains optional** — camera-based features do not make a camera a device requirement.
- ▶️ **Traditional red play-mark launcher icon**.

## 📥 Install

Get the APK from [Releases](https://github.com/metaljay/Flow_AAOS/releases). This fork is intended for Android Automotive OS, with the **Polestar 3** as its primary target.

## ⚠️ Compatibility

The app includes AAOS-specific integration and larger-display adjustments. Emulator testing does not guarantee compatibility with every Polestar 3 hardware or software configuration. Android Auto is a separate platform and is not implied by AAOS support.
